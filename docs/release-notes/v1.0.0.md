## Saturn Bomberman Recomp v1.0.0

First release. Runs **Saturn Bomberman (USA)** on Windows through the
[SaturnRecomp](https://github.com/sonsegajp/SaturnRecomp) runtime, booting **your own**
Saturn BIOS and **your own** disc. No BIOS, disc image or game data is included.

### What works
- Boots through the real BIOS, passes the SEGA licence screen, plays the intro FMV,
  reaches the title screen and the menus, and starts Normal Game (story).
- Vulkan renderer (default) and the software renderer (`SATURN_RENDERER=software`).
- Keyboard and XInput-style gamepad on player 1; **F1** settings overlay.

### Runtime fixes in this version (also sent upstream as sonsegajp/SaturnRecomp#2)
- SH-2 FRT compare/overflow interrupts on the master CPU and the SH7604 watchdog timer.
- CD block current directory (Change Directory command).
- VDP1 draw timing in the Vulkan renderer (black screen after the intro).
- NetLink modem stub now opt-in (`SATURN_NETLINK=1`).

### Known limits
- The game code still runs on SaturnRecomp's SH-2 interpreter, not as statically
  recompiled C.
- One controller only (no second player, no multitap).
- Backup RAM is not written to disk; in-game saves may be lost on exit.
- Full stages, Battle mode and audio have only been lightly tested.

### Install
Download `saturnbomberman-1.0.0-windows-x64.zip`, extract the whole folder and follow
the **Install from a release** section of the README (English and Português).
`SHA256SUMS` holds the checksum of the ZIP.
